-  There are 3 seasons, each with 3 themes
-  Seasons unlock like a mystery box
-  When total participant coding hours reach a target → next season unlocks
    (target time: TBD)

### How does the shop work?

- The shop is fully run by you guys. You can choose whatever you want and it will be added to the shop. Add your suggestions here - Shop item suggestions
- Every item in the shop is priced in Aqua Regia, and anything can be bought with Aqua Regia earned on any theme.

## Rules

Please read the rules carefully


#### 📜 RULES

-  Max 30% AI usage → exceed 30% = rejection 
- No double dipping with other YSWS events 
-  No cheating (fake hours, hackatime abuse, etc.) → permanent HC ban

#### 📦 SHIPPING REQUIREMENTS

You must submit:

-  GitHub username 
-  GitHub repo link 
- Playable URL (no downloads as much as you can) 
-  Banner image (screenshot or project visual)

🔴 BASE PROJECT

##### 💻 Software

Examples: websites, apps, games, etc.

-  Track time using Hackatime
-  Commit every 30–60 minutes

##### 🔧 Hardware

Examples: electronics, physical builds

-  Track time using lapse
-  If coding is involved → must use Hackatime
    (coding time via Lapse = rejected)

#### ➕ ADDONS

Addons are the things you do in addition to your base project, like designing assets for your game, creating a trailer or a tutorial video for your app. That counts as an addon.

⏱️ Addon Time Rule

-  Must be ~15% of coding time
-  Example: 
-  10h coding → max ~1.5h addon 
-  Excess addon time = rejected (Sorry this is a RULE and we need to follow this)
-  Use Addon Journey to track addon time
-  Addon Journal Should be detailed and include:
    -  What you did 
    -  How it relates to your project 
    -  Time spent on each addon activity
    - Screenshots or evidence of the addon work(MUST)
    - Ideally 150+ words per addon entry to show the thought process and effort put into it.
    - A good addon journal is the difference between a rejected and accepted project, so please take this seriously.

**Here is a list of what counts as addon and what doesn't**
